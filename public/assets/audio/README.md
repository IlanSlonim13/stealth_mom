# Audio Assets

Place the following `.mp3` files here. Until they exist, the AudioManager silently skips playback.

| File | Description |
|------|-------------|
| `ambient-hum.mp3` | Looping background ambience (quiet house hum) |
| `footstep-soft.mp3` | Sneaking footstep on carpet |
| `squeak.mp3` | Squeaky toy sound |
| `caught-mommy.mp3` | Toddler: "MOMMY!" |
| `caught-dog.mp3` | Dog bark |
| `caught-husband.mp3` | Husband: "What's for dinner?" |
| `success-confetti.mp3` | Level complete fanfare |
| `decoy-throw.mp3` | Keys being thrown / jingling |
